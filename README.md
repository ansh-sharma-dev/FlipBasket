# 🛒 FlipBasket

A responsive e-commerce web application built with HTML, CSS, and JavaScript, designed to provide a complete online shopping experience.

## 🚀 Live Demo

**[Visit FlipBasket](https://ansh-sharma-dev.github.io/FlipBasket/)**

## ✨ Features

### 👤 User Authentication
- Sign Up / Registration
- Login functionality
- User information stored using LocalStorage
- Logged-in user welcome display

### 🛍️ Shopping
- Product browsing
- Product search
- Add products to cart
- Buy Now functionality
- Increase / decrease product quantity
- Remove products from cart
- Total price calculation

### ❤️ Wishlist
- Add products to wishlist
- Manage wishlist items using LocalStorage

### 📦 Orders
- Place orders
- Order confirmation flow
- Cart automatically cleared after placing an order

### 🎨 User Experience
- 🌙 Dark Mode
- 🔔 Toast notifications
- 📱 Responsive design
- Interactive navigation and UI

## 💾 Data Management

The project uses **Browser LocalStorage** to persist:

- User account information
- Login state
- Cart items
- Wishlist items
- Order-related data

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- Git
- GitHub

## 📂 Project Overview

FlipBasket is a frontend e-commerce project built to practice real-world web development concepts using vanilla JavaScript.

The project includes user authentication, product search, shopping cart management, wishlist functionality, order placement, dark mode, and persistent browser storage.
